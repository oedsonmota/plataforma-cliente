# Plataforma do cliente Edson Mota

Portal onde cada cliente de projeto de marca acompanha etapas, cronograma e entregas.

- Site estático hospedado no GitHub Pages: https://plataforma.edsonmota.com
- Login e dados no Supabase (projeto `plataforma-cliente`)
- `config.js` tem só a chave pública (publishable). Os dados são protegidos pelas regras de acesso (RLS) do banco.
